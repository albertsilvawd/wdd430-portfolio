# WDD 430 Portfolio

My first Next.js application for WDD 430 - Web Full-Stack Development (BYU-Pathway).

## Live Site

https://wdd430-portfolio-one-eta.vercel.app/

## Features

- Home page with a list of my projects (ProjectList and ProjectCard components)
- About page with a custom SkillCard component
- Shared Header and Footer in the root layout
- Simple API route at `/api/hello`

## Technologies

Next.js (App Router), React, TypeScript, Tailwind CSS, Vercel

## Run Locally

npm install
npm run dev

Then open http://localhost:3000
